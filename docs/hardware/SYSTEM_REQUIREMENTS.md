# 系统需求规格说明书 (System Requirements Specification)

**文档编号**: ENG-REQ-001  
**项目名称**: Kindle Remote 工业级实体翻页器硬件量产项目  
**版本**: v1.0.0  
**编制日期**: 2026-10-14  

---

## 1. 产品定义与用户场景

### 1.1 产品定义
本产品是一款专为 Amazon Kindle 电子墨水屏阅读器（特别是 Kindle Paperwhite 2024 第 12 代及搭载 5.20.1+ 固件的设备）设计的**超便携、低功耗、高可靠度实体无线蓝牙翻页遥控器**。

### 1.2 目标使用场景
1. **支架/懒人支架远距离阅读**: Kindle 固定在桌面或床头悬臂支架上，用户手持翻页器在被窝中或沙发上轻松单手盲操翻页。
2. **侧卧/冬季被窝单手盲操**: 无需抬臂触摸墨水屏表面，拇指自然下沉即可触发下一页，支持微弱震动触觉反馈感知翻页成功。
3. **免充电压迫感**: 充电一次可支持重度阅读者使用 1~2 个月以上，半年超长待机。

## 2. 功能需求矩阵 (Functional Requirements)

### 2.1 无线通信与主机适配 (REQ-BLE)
- **REQ-BLE-01 (协议栈)**: 采用 BLE 5.0 / 5.2 HID Over GATT Profile (HOGP)，支持标准 LE 1M PHY 与 LE 密码安全连接 (SMP)。
- **REQ-BLE-02 (广播绕过)**: 广播包必须注入 Amazon 官方 VID `0x0171` 与 PID `0x0443`（AD Type `0xFF` 载荷 `[71 01 04 43]`），确保在 Kindle 蓝牙扫描阶段被 `acsbtfd` 过滤算法判定为合法设备并上屏显示。
- **REQ-BLE-03 (白名单伪装)**: DIS 服务 (`0x180A`) 必须下发标准 7 字节 PnP ID (`02 71 01 43 04 00 01`)，固件版本特征 (`0x2A26`) 必须响应 `"1.0.0"`，通过 `input_manager` 白名单检验。
- **REQ-BLE-04 (自动重连)**: 配对密钥持久化存入 NVS/Flash。在 Kindle 开机或唤醒后，翻页器任意按键唤醒应在 1.5 秒内完成定向广播与加密链路重连。

### 2.2 按键输入与人机交互 (REQ-HMI)
- **REQ-HMI-01 (下一页按键 NEXT)**: 正面主按键，发送 Usage `0x4E` (`KEY_PAGEDOWN`)，40ms 硬件保持后自动发送全零释放帧。
- **REQ-HMI-02 (上一页按键 PREV)**: 正面上副按键，发送 Usage `0x4B` (`KEY_PAGEUP`)，40ms 保持与释放。
- **REQ-HMI-03 (电源/功能键 PWR)**:
  - 短按（连接态）: 发送 Usage `0x66` (`KEY_POWER`) 触发 Kindle 熄屏休眠或点亮唤醒。
  - 长按 3 秒: 强制重新进入 BLE 广播配对模式（蓝灯快闪）。
  - 长按 6 秒: 软关机/极低功耗待机。
- **REQ-HMI-04 (状态指示灯 LED)**:
  - 红色 LED: 充电中常亮，充满熄灭。
  - 蓝色 LED: 广播配对中快闪 (2Hz)，已连接慢闪 3 次后熄灭，按键按下微闪一次。
  - 低电告警: 电量 $\le 15\%$ 时，每次翻页蓝灯伴随红灯闪烁 2 次。
- **REQ-HMI-05 (触觉震动反馈 Haptic)**:
  - 内置 0827 / 1027 微型扁平转子电机，翻页成功输出 18ms 清脆短震。
  - 具备物理开闭功能：双击电源键可在“开启震动”与“静音模式”间快速切换。

### 2.3 电源管理与电池寿命 (REQ-PWR)
- **REQ-PWR-01 (电池方案)**: 采用 3.7V 200mAh 聚合物锂电池，带独立过充、过放、短路保护板。
- **REQ-PWR-02 (充电方案)**: 具备标准 USB Type-C 接口，内置锂电恒流恒压充电管理芯片，充电电流 100mA，充满电压 $4.20\text{V} \pm 1\%$。
- **REQ-PWR-03 (电量遥测)**: 板载低漏电 ADC 分压检测电路，实时采集电芯电压转换为 0~100% 并通过 BAS (`0x180F`) 上报 Kindle。
- **REQ-PWR-04 (低功耗策略)**:
  - 活跃翻页电流: $\le 15\text{ mA}$ (峰值持续 $\le 50\text{ ms}$)。
  - 连接空闲态 (Connected Idle): $\le 1.2\text{ mA}$ (保持 45ms 连接间隔)。
  - 深度睡眠态 (Deep Sleep): 无按键操作 3 分钟后进入深度休眠，整机待机漏电 $\le 12\ \mu\text{A}$，由物理按键引脚中断外部唤醒。

### 2.4 生产与测试接口 (REQ-PROD)
- **REQ-PROD-01 (出厂测试与烧录)**: PCB 背面预留 1.27mm / 2.54mm 镀金测试点（GND, 3V3, VBUS, TXD, RXD, BOOT0, EN），支持夹具顶针一键烧录与全自动功能质检。
- **REQ-PROD-02 (USB 恢复)**: USB Type-C 接口连接电脑时可作为紧急调试串口与固件更新口。

## 3. 非功能性需求 (Non-Functional Requirements)

- **NFR-01 (可制造性 DFM)**: 所有电子器件必须选用现货充足、生命周期稳定的大厂或国产高可靠主力料；PCB 设计采用标准双面贴片工艺。
- **NFR-02 (成本目标 Target Cost)**: 小批量（100 套）整机 BOM 成本控制在 **18 ~ 25 元人民币**；千套批量整机 BOM 成本控制在 **12 ~ 15 元人民币**。
- **NFR-03 (结构抗跌落)**: 外壳配合结构坚固，能承受 1.2 米高处自然跌落至木地板无壳体脱开或电子失效。
- **NFR-04 (环保与安规)**: 全制程满足 RoHS 环保指令，无铅焊接。
