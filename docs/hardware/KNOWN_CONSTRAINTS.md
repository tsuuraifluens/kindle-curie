# 物理设计与制造工程约束矩阵 (Known Constraints)

**文档编号**: ENG-CONST-001  
**生成日期**: 2026-10-14  
**项目**: Kindle Remote 工业级实体翻页器硬件设计

---

## 1. 机械尺寸与人体工学约束 (Mechanical & Ergonomic Constraints)

### 1.1 手持操作形态定义
- **目标形态**: 紧凑手持遥控器 / 掌心水滴型指尖阅读翻页器（Handheld Ergonomic Clicker）。
- **最大外轮廓尺寸边界**:
  - 长度 (Length): $\le 68.0\text{ mm}$
  - 宽度 (Width): $\le 30.0\text{ mm}$
  - 厚度 (Thickness): $\le 16.5\text{ mm}$（含按键突起部分）
- **重量限制**: 整机（含锂电池与外壳）目标重量 $\le 32\text{ g}$，长时间单手持握（侧卧、被窝、支架阅读）无坠手感与疲劳感。
- **PCB 目标尺寸边界**: 
  - 长度: $50.0\text{ mm} \pm 0.5\text{ mm}$
  - 宽度: $22.0\text{ mm} \pm 0.5\text{ mm}$
  - 板厚: $1.2\text{ mm}$ 或 $1.6\text{ mm}$ 双层 FR-4。

### 1.2 人机交互布局 (HMI Layout)
1. **主翻页按键 (下一页 / NEXT)**: 面积最大，位于拇指自然下沉受力点（正面偏下），触移行程清晰，按压力度 $1.2\text{ N} \sim 1.6\text{ N}$。
2. **副翻页按键 (上一页 / PREV)**: 位于主按键上方，尺寸略小或带有盲触凸点区分。
3. **功能侧键 / 顶键**: 
   - 独立电源/配对按键（按压开机、长按 3 秒进入配对/广播、单按触发 Kindle 熄屏/唤醒）。
4. **指示灯窗口**: 隐藏式微孔双色 LED（绿/红或蓝/红），指示充电状态、BLE 连接状态与低电告警。
5. **充电接口**: 正面底部标准 USB Type-C 接口（仅需 24Pin 中的 6Pin/16Pin 简化贴片封装），支持正反盲插。

## 2. 电源管理与功耗约束 (Power & Battery Constraints)

### 2.1 电池形态与容量选型
- **选型方案**: 紧凑型聚合物锂离子电池 (LiPo Pouch Battery)，带精密二次过充/过放保护板 (PCM)。
- **电池规格型号**: **402030** (厚度 4.0mm, 宽度 20mm, 长度 30mm) 或 **502030** (厚度 5.0mm, 宽度 20mm, 长度 30mm)。
- **额定容量**: $200\text{ mAh} \sim 250\text{ mAh}$ @ 3.7V (约 0.74 ~ 0.925 Wh)。
- **目标续航要求**:
  - 每日深度阅读 3 小时（按每分钟翻页 2 次，共 360 次按键翻页）。
  - 连接态 BLE 通信与广播功耗优化后平均工作电流 $\le 1.8\text{ mA}$。
  - 静态深度睡眠 (Deep Sleep) 漏电流 $\le 15\ \mu\text{A}$。
  - **连续工作续航**: $\ge 110\text{ 小时}$。
  - **待机保持时间**: $\ge 180\text{ 天}$（满足半年无需充电）。

### 2.2 充电与安全保护约束
- **充电电流预算**: 锂电池 0.5C 充电速率，充电电流设定为 $100\text{ mA} \sim 120\text{ mA}$。
- **充电耗时**: $\le 2\text{ 小时}$ 完全充满。
- **热管理与安全**: USB Type-C 供电端具备 500mA 自恢复保险丝 (PTC / PPTC)、ESD 瞬变二极管防护，且锂电池必须具备板载或电芯自带保护板（DW01A + FS8205A 等防反接过放保护）。

## 3. 射频性能与天线净空约束 (RF & Antenna Keep-out Constraints)

### 3.1 2.4 GHz BLE 天线净空区
- **天线类型**: PCB 板载倒 F 型天线 (On-board Meandered Inverted-F Antenna, MIFA) 或陶瓷贴片天线 (Ceramic Chip Antenna)。若采用模组方案，优先采用经认证的板载 PCB 天线模组（如 ESP32-C3-WROOM-02 或 ESP32-S3-MINI-1）。
- **禁布区 (Keep-out Zone)**:
  - 天线辐射区域下方及周围至少 **$15\text{ mm} \times 8\text{ mm}$** 区域内，PCB 顶层与底层**严禁铺铜、走线或打过孔**。
  - 结构装配时，锂电池铝箔外壳、金属螺丝、USB Type-C 金属铁壳必须距离天线辐射边 $\ge 7\text{ mm}$，防止发生强烈的介电损耗或阻抗失配导致的通信距离衰减。
- **通信距离指标**: 墨水屏阅读环境多为室内 $1\text{ m} \sim 5\text{ m}$，要求在 $-20\text{ dBm}$ 接收灵敏度余量下实现半径 $\ge 8\text{ 米}$ 稳定无丢包传输。

## 4. PCB 制造工艺与可量产性约束 (DFM / DFX Constraints)

### 4.1 制造工艺级别 (基准: 标准 2 层 FR-4 工业化低成本制程)
- **层数**: 2 层板 (Top Layer / Bottom Layer)，厚度 1.2mm 或 1.6mm。
- **最小线宽 / 线距 (Min Trace / Space)**: $6\text{ mil} / 6\text{ mil}$ ($0.15\text{ mm} / 0.15\text{ mm}$)，完全兼容国内主流快板厂（嘉立创、捷多邦、华秋）基础制程。
- **最小钻孔与孔径 (Min Via Hole / Ring)**: 机械钻孔 $0.3\text{ mm}$，外环 $0.5\text{ mm}$。
- **阻焊与表面处理**: 哑光黑或阻焊绿油，表面处理优先选用**沉金 (ENIG 1U)** 或无铅喷锡 (HASL Lead-Free)，确保贴片焊盘平整度。
- **贴片器件封装尺寸**:
  - 被动阻容感器件: 优先采用 **0603** 或 **0402** 封装（兼顾高密度贴片与手工返修容错性）。
  - 主动芯片: 优先选择带引脚封装（如 SOT-23, SOP-8, DFN-8）或引脚间距 $\ge 0.5\text{ mm}$ 的 QFN 封装。

## 5. 3D 打印与模具公差约束 (Additive Manufacturing & Fit Constraints)

### 5.1 FDM / SLA 打印成型公差
- **打印材料选型**: 
  - 原型首件试制: PETG 或 高韧性光敏树脂 (SLA 8000)。
  - 量产功能件: PETG（抗冲击、耐汗液侵蚀、不易断裂）或 ABS。
- **壳体壁厚 (Wall Thickness)**: 外壳主壁厚设定为 **$1.6\text{ mm} \sim 2.0\text{ mm}$**，按键柱与加强筋壁厚设定为 **$1.0\text{ mm} \sim 1.2\text{ mm}$**。
- **配合装配间隙 (Mating Clearance)**:
  - 上盖与底壳止口 (Lip & Groove) 配合间隙: 单边预留 **$0.25\text{ mm}$**。
  - 实体微动按键导向孔与外露按键帽四周间隙: 单边预留 **$0.30\text{ mm}$**（防止 FDM 打印层纹挂擦卡键）。
  - Type-C 母座开口周边间隙: 单边预留 **$0.40\text{ mm}$**（兼顾各类充电线端子外壳防干涉）。
- **机械紧固结构**:
  - 采用 **M2 热熔黄铜滚花螺母 (M2 × 3.0mm × OD 3.5mm)** 预埋在底壳沉孔螺丝柱内。
  - 固定螺丝采用 4 颗 **M2 × 6mm 内六角沉头螺钉**，避免纯塑料自攻螺丝多次拆装后滑丝损坏外壳。
