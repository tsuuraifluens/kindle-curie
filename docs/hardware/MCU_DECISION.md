# MCU 方案最终定型决策记录 (MCU Decision Record)

**文档编号**: ENG-DEC-MCU-001  
**状态**: APPROVED (已定型)  
**决策人**: 系统架构组 / 硬件工程组 / 固件工程组  
**日期**: 2026-10-14  

---

## 1. 决策结论 (Decision Summary)

经过对当前 ESP32-S3 原型、ESP32-C3 系列模组、WCH CH582 系列及 Nordic nRF52840 进行深度架构对比、功耗推演、固件可重用性测试及阶梯成本测算，最终决策如下：

- **主选推荐量产方案 (Primary / Selected)**:
  **Espressif ESP32-C3-WROOM-02-N4 (板载 PCB 天线模组，内置 4MB Flash)**。
- **次选备用兜底方案 (Secondary / Fallback)**:
  **Espressif ESP32-S3-MINI-1-N8 (紧凑型双核模组)**。

---

## 2. 推荐主选方案的核心支撑依据 (Justification)

1. **固件资产平滑继承，零协议栈兼容性风险**:
   ESP32-C3 与 ESP32-S3 共享完全相同的 ESP-IDF (v5.3.2) 驱动与 NimBLE 架构。现有已通过 25/25 项自动化测试验证的 0xFF 厂商广播绕过算法、DIS PnP ID 白名单、HIDS 92 字节复合键盘描述符以及翻页状态机代码，在 ESP32-C3 上可实现 **100% 源码级无缝复用**，彻底消除推倒重写其他 MCU 协议栈所面临的 Kindle 蓝牙断连、丢包与被丢弃风险。
2. **硬件内置 USB Serial/JTAG，彻底省去外部串口芯片**:
   ESP32-C3 的 GPIO18 与 GPIO19 原生集成全速 USB 物理层与 USB Serial/JTAG 单元。无需像开发板那样额外焊接 CH343 / CH340 芯片，即可直接通过 Type-C 接口连接 PC 实现调试日志输出、Python 自动化控制与 ROM 固件烧录。这一特性不仅节省了 **2.5 元** 的芯片及阻容物料成本，还显著缩减了 PCB 走线空间。
3. **低功耗性能优异，待机时间延长数倍**:
   ESP32-C3 的 RISC-V 单核架构功耗远低于 ESP32-S3 双核架构。在 Deep Sleep 模式下整机休眠漏电仅约 **5 μA**，配合按键中断唤醒策略，200mAh 锂电池可支持正常阅读使用数月，半年无需充电。
4. **极致的量产经济性**:
   ESP32-C3 模组单价低至 **8.20 元**（百片小批量），相比 ESP32-S3 模组的 18.50 元直接降低超过 55%，单板综合降本超过 13 元。

---

## 3. 次选方案的保留与启用触发条件 (Fallback Trigger)

保留 **ESP32-S3-MINI-1-N8** 作为备用方案：
- **触发条件**:
  若后期产品规划要求增加复杂本地音频解码、离线大容量语音控制、彩色大屏显示扩展，或遭遇不可抗力的 ESP32-C3 区域性供应链断货。
- **工程应对预案**:
  硬件 PCB 库中已预备 ESP32-S3-MINI-1 原理图符号与引脚映射表，二者在固件上可无缝构建切换。
