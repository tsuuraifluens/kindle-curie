# MCU 选型与技术路线全面对比论证 (MCU Comparison)

**文档编号**: ENG-EVAL-MCU-001  
**编制日期**: 2026-10-14  
**项目**: Kindle Remote 工业级实体翻页器硬件量产化  

---

## 1. 候选方案概览与技术特征

根据项目需求，控制器需长期独立运行，支持 BLE 5.0 HOGP 键盘模拟、低功耗按键中断唤醒、USB 充电与出厂免外部转串口芯片烧录。我们筛选出 4 种具备代表性的候选技术方案：

1. **方案 A: 继承基准 - ESP32-S3 紧凑模组 (ESP32-S3-MINI-1-N8)**
2. **方案 B: 推荐量产 - 乐鑫 ESP32-C3 系列模组 (ESP32-C3-WROOM-02-N4)**
3. **方案 C: 国产极致低成本 - 沁恒 WCH CH582M (QFN28 单芯片)**
4. **方案 D: 工业级低功耗标杆 - Nordic nRF52840 (nRF52840-QIAA / 模组)**

## 3. 关键架构分析与技术论证

### 3.1 为什么 ESP32-C3 是最理想的量产方案？
1. **现有固件资产 100% 保护**:
   原型固件基于 ESP-IDF v5.3.2 与 NimBLE 架构编写。ESP32-C3 与 ESP32-S3 共享完全相同的 `esp_bt_controller`、NimBLE 主机协议栈、NVS 存储、FreeRTOS 以及外设抽象 API。将目标从 `esp32s3` 切换至 `esp32c3`，代码几乎可以一字不改直接编译通过，完全规避了移植到其他平台可能引入的隐蔽 BLE 兼容性 Bug（特别是 Kindle 严苛的 0xFF 厂商广播包与 PnP ID 握手）。
2. **免外部 USB-UART 芯片降低成本与布线面积**:
   ESP32-C3 内部集成了 USB Serial/JTAG 控制器（引出至 GPIO18 / GPIO19）。这意味着产品只需要将 Type-C 的 D+/D- 接入这两个引脚，即可在出厂或售后维护时直接连接电脑实现标准 CDC 串口通信与 ROM 下载烧录，**无需额外采购 CH340 / CH343 / CP2102 芯片（立省 1.5 ~ 2.5 元 BOM 成本与 10 余个阻容器件）**。
3. **功耗特性显著优于 ESP32-S3**:
   翻页器是典型的低事件触发型便携设备。ESP32-C3 采用精简的 32 位 RISC-V 单核，运行功耗比双核 ESP32-S3 降低约 50%，在 Deep Sleep 模式下整机漏电仅 5μA 级别，配合按键 GPIO 唤醒，200mAh 电池可轻松实现长达 3~6 个月的待机。

### 3.2 为什么不选 WCH CH582M 或 Nordic nRF52840？
- **CH582M 的陷阱**: 尽管芯片单价低至 4 元，但芯片为 QFN28 裸片，需要自主设计 50 欧姆天线阻抗微带线和 π 型匹配滤波网络，两层 PCB 的板材介电常数离散度极易导致天线失配、通信距离骤降；且必须全面推翻重写固件，工程人力与试错成本远超硬件节省的微薄差价。
- **nRF52840 的过剩与高价**: 芯片单价超过 35 元，对于一款仅需发送 `PageUp` / `PageDown` 两个键码的阅读器配件来说属于严重过度设计，性价比极低。

---

## 4. 结论与选型决策
- **正式推荐方案**: **ESP32-C3-WROOM-02-N4 模组方案**。
- **备用兜底方案**: **ESP32-S3-MINI-1-N8 模组方案**（当需严格保持双核算力或有其他未披露的高负荷扩展需求时直接无缝平替）。
