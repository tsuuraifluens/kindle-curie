## 2. 关键补丁候选地址与二进制结构 (Candidate Patch Map)

通过对 `decrypted.bin` 与 `app.bin` 的精准逆向映射，定位到以下可修改的文件偏移：

### 2.1 补丁点 1: PnP ID 与设备标识常量表 (修改难度: 极低)
- **文件与偏移**:
  - `app.bin` 相对偏移: `0x223BC` ~ `0x223C4`
  - `decrypted.bin` 绝对偏移: `0x244DC` ~ `0x244E4`
  - 映射虚拟执行地址: `0x01E224DC`
- **原始十六进制字节**:
  ```text
  11 01 00 03 3B 05 07 10 00 00
  ```
  *(注: `3B 05` 为 VID 0x053B; `07 10` 为 PID 0x1007)*
- **目标修改字节 (Amazon 白名单)**:
  ```text
  11 01 00 03 71 01 43 04 00 01
  ```
  *(注: `71 01` 改为 VID 0x0171; `43 04` 改为 PID 0x0443; 版本改为 0x0100)*
- **修改理由**: 强制让手柄在蓝牙连接后的 GATT DIS 嗅探中返回 Amazon 官方翻页器身份，击穿 `input_manager` 的 `devices.json` 白名单拦截。

### 2.2 补丁点 2: 厂商字符串修改 (修改难度: 极低)
- **文件与偏移**:
  - `app.bin` 相对偏移: `0x22384`
  - `decrypted.bin` 绝对偏移: `0x244A4`
- **原始字节**: `7a 68 75 68 61 69 5f 6a 69 65 6c 69 00` (`"zhuhai_jieli\0"`, 13 字节)
- **目标修改字节**: `41 6d 61 7a 6f 6e 00 00 00 00 00 00 00` (`"Amazon\0"`, 补零保持 13 字节)

### 2.3 补丁点 3: 广播名称修改 (修改难度: 低)
- **文件与偏移**:
  - `app.bin` 相对偏移: `0x211C6`
  - `decrypted.bin` 绝对偏移: `0x232E6`
- **原始字节**: `49 49 4e 45 5f 72 65 61 64 65 72 00` (`"IINE_reader\0"`, 12 字节)
- **目标修改字节**: `4b 69 6e 64 6c 65 2d 50 54 00 00 00` (`"Kindle-PT\0"`, 保持 <=12 字节避免溢出)

### 2.4 补丁点 4: 按键消费类 Usage 键码修改 (修改难度: 中，存在架构局限)
- **文件与偏移**:
  - `app.bin` 相对偏移: `0xE7AC` 与 `0xE7B0`
  - `decrypted.bin` 绝对偏移: `0x108CC` 与 `0x108D0`
- **原始汇编代码**:
  ```arm
  0xE7AC: F582 00EA    mov r2, #0x00EA         ; Volume Down (下一页)
  0xE7B0: F581 00E8    mov r1, #0x00E8 / 0xE9  ; Volume Up (上一页)
  ```
- **核心风险与局限性**:
  若直接将其修改为 `0x004E` (`PageDown`) 与 `0x004B` (`PageUp`)，由于当前模式调用的发送通道依然是 **Consumer Control 描述符 (Usage Page 0x0C)**，Linux 内核与 Kindle `hid-input` 驱动会将 `0x004E` 翻译为消费类事件（如 `Menu Pick`），而**绝对不会**被识别为键盘类的 `KEY_PAGEDOWN`！
  **要真正生效，必须将按键发射函数切换至已存在的键盘发送通道 (`HID_TYPE_KB` / Report ID 2)**。
