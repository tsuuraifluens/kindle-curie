## 1. 产线测试架构与环境拓扑

生产测试采用全自动化计算机测试系统 (ATE)，由 ATE 工控机、夹具针床、数字可编程直流电源 (Keithley / 程控直流稳压器) 及 BLE 射频嗅探仪组成：

```
 +-------------------------------------------------------------------------+
 |                     产线工控机 ATE 自动化测试软件                       |
 |             (Python 自动化驱动脚本 / 扫码枪 / 产线数据库)               |
 +-------------------------------------------------------------------------+
       | (USB CDC)                     | (RS232/GPIB)             | (BLE 5.0)
       v                               v                          v
 +------------------+        +-------------------+      +------------------+
 |  烧录器 / UART   |        | 可编程直流稳压源  |      | BLE 射频嗅探器   |
 |  (921600 bps)    |        | (高精度电流检测)  |      | (Dongle / 衰减室)|
 +------------------+        +-------------------+      +------------------+
       |                               |                          |
       +---------------+---------------+                          |
                       | (针床顶针触点)                           | (无线射频)
                       v                                          v
 +-------------------------------------------------------------------------+
 |                  被测 PCBA 板卡 (Kindle Remote)                         |
 |   [TP_VBUS] [TP_GND] [TP_3V3] [TP_TX] [TP_RX] [TP_IO0] [TP_EN]         |
 +-------------------------------------------------------------------------+
```

## 2. 九步流水线自动化测试规程 (9-Step Production Test Procedure)

### Step 1: 接触阻抗与电源短路初检 (Pre-Power Safety Guard)
- **测试动作**: 夹具下压，数字源表未上电前检测 `TP_VBUS` 与 `TP_3V3` 对地阻抗。
- **合格标准**:
  - `TP_VBUS` 对地阻抗 $\ge 100\text{ k}\Omega$。
  - `TP_3V3` 对地阻抗 $\ge 20\text{ k}\Omega$。
  - 判定: 若发现阻抗 $< 50\ \Omega$，判定短路，立即锁定严禁送电，红灯报警。

### Step 2: 固件极速烧录与启动校验 (Flashing & Booting)
- **测试动作**: 直流源供电 5.0V，拉低 `TP_IO0` 并触发 `TP_EN` 复位，调用 `esptool` 烧录 3 个二进制分包。
- **合格标准**:
  - `esptool` 返回 `Hash of data verified`，烧录退出码 `exit code = 0`。
  - 释放 `TP_IO0`，芯片硬复位，100ms 内在串口 (115200 8N1) 捕获启动 Banner 字符串：`PRODUCTION HARDWARE FIRMWARE (v1.1.0-prod ESP32-C3)`。

### Step 3: 板载核心协议自检回归 (`selftest`)
- **测试动作**: ATE 自动向串口发送命令 `selftest\r\n`。
- **合格标准**:
  - 返回全部 7 项协议编解码断言通过：`Result: 7 / 7 tests passed (ALL PASSED)`。
  - 严格校验 PnP ID、AD 0xFF 厂商字节及 92 字节复合报告描述符。

### Step 4: 充电管理与电量采样校准 (Power & Battery Telemetry)
- **测试动作**:
  - 测量 `TP_3V3` 稳压输出: 必须在 $3.25\text{V} \sim 3.35\text{V}$ 之间。
  - 夹具切换 `TP_VBAT` 模拟电芯电压至 $3.80\text{V}$，ATE 发送命令 `battery` 触发采样。
  - 检查固件 ADC 读数: 汇报值应在 $3750\text{ mV} \sim 3850\text{ mV}$（误差 $\le \pm 1.5\%$）。

### Step 5: 实体按键接触与状态机核验 (Tactile Buttons Test)
- **测试动作**: 夹具气缸依次顶推或人工依次按下 SW1 (NEXT)、SW2 (PREV)、SW3 (PWR)。
- **合格标准**:
  - ATE 串口分别监听到带时间戳的事件日志：
    - `[BTN] Hardware button NEXT pressed (GPIO 1)`
    - `[BTN] Hardware button PREV pressed (GPIO 0)`
    - `[BTN] Hardware button PWR pressed (GPIO 5)`
  - 释放按键后电平立即恢复高电平，无卡键悬空。

### Step 6: 触觉震动马达脉冲与功耗测试 (Haptic Motor Test)
- **测试动作**: ATE 发送指令 `key 4E`，触发震动。
- **合格标准**:
  - 电流表检测到持续 $18\text{ ms} \pm 2\text{ ms}$ 的瞬态电流脉冲（幅值约 $40\text{ mA} \sim 50\text{ mA}$）。
  - 超时后电流立即回落，肖特基二极管无异常发热。

### Step 7: 状态指示灯功能核验 (LED Inspection)
- **测试动作**: 自动循环点亮红灯、绿灯、蓝灯，夹具光电传感器感应色温或人工目检。
- **合格标准**:
  - 充电红灯常亮正常。
  - 充满绿灯常亮正常。
  - BLE 蓝灯闪烁正常。

### Step 8: BLE 射频天线与广播白名单测试 (RF & ADV Test)
- **测试动作**: 射频嗅探仪监听 37、38、39 广播信道。
- **合格标准**:
  - 必须捕获到广播设备名为 `"Kindle Remote"`。
  - 广播负载精确包含 `[05 FF 71 01 04 43]`。
  - 距离 1 米处实测 RSSI 信号强度 $\ge -62\text{ dBm}$（证明天线无虚焊、阻抗匹配良好）。

### Step 9: 静态休眠低功耗测试与设备溯源存档 (Deep Sleep & Serialization)
- **测试动作**: 发送休眠命令进入 Deep Sleep，高精度微安表测量静态供电电流。
- **合格标准**:
  - 整板待机漏电流 $\le 12\ \mu\text{A}$。
- **出厂归档**: ATE 读取芯片唯一 MAC 地址，生成连续生产序列号（如 `KR20261014-0001`），将测试时间、全部 9 项测试值与操作员工号写入生产数据库 `manufacturing/production_records.csv`。打印条形码标签贴于防静电包装袋。
