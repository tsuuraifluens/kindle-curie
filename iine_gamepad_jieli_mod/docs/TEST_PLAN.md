## 4. 通过条件

- A/B、方向键、亮度全部正常。
- A+B 至少能触发一次熄屏。
- 无按键卡死、无异常断连、无无法重连。

## 5. 失败分支

- **A+B 不触发**: 两键可能不在同一扫描周期；需要短窗口/锁存。
- **A+B 松开误翻页**: 加组合键锁存，释放时屏蔽剩余键。
- **Power 重复**: 限制聚合函数只在一个调用路径触发。
- **全键失效**: 检查描述符指针 `0x1E23450` 与 trampoline 落点；
  回退 v22s。
- **启动/蓝牙异常**: 停止刷写，用原厂 UFW 恢复。

## 6. 未验证

- 任意键开机（当前只有配对键能开机）。
- 电池电量服务/低电量提示的实机行为。
- 长时间待机电流与自动休眠策略。
- Kindle 被遥控器睡眠后的唤醒（协议上不支持遥控器唤醒）。
