# 按键 GPIO 测量指引 (万用表)

目标: 确定每个按键接到 AC6321A (QFN32) 的哪个引脚, 以便在固件中做按键扫描。

## 工具
数字万用表(蜂鸣/通断档), 放大镜(可选), 拆机螺丝刀。

## 步骤
1. 拆开手柄外壳, 取出主板。先拍照正反面存档(高清)。
2. 找到 QFN32 主控 (丝印 BP3F723-21A4)。
3. 观察按键: 每个按键是一个薄膜/轻触开关, 两脚, 一脚通常接 GND(地), 另一脚接主控 GPIO。
4. 万用表蜂鸣档, 一端接按键的一个焊盘, 另一端在主控 32 个引脚(或金手指/测试点)上滑动:
   - 与按键焊盘直通的引脚即该按键的 GPIO。
   - 一般按键另一端接公共地, 可用通断档确认 GND 网络。
5. 记录: 每个按键 → GPIO 编号(如 PA0/PA5/PB3...), 对照 AC6321A 数据手册引脚表写全名。
6. 顺便识别: 电池正极到主控是否有分压电阻接入某 GPIO(ADC); 充电管理 IC 型号; LED 接哪个 GPIO; USB D+/D- 走向。

## 建议记录表
| 按键 | GPIO | 备注 |
|---|---|---|
| 配对键 | | |
| A/B 键 | | |
| 方向键上/下/左/右 | | |
| 肩键 L/R (若有) | | |
| LED | | |
| 电池分压 ADC | | |
| USB D+/D- | | (应接主控 USB 口, 用于升级) |

## 注意事项
- 主板可能有多层/镀膜, 触点要刮开氧化层再测。
- 记录时对照数据手册 `analysis/reference/fw-AC63_BT_SDK/doc/datasheet/AC632N/AC6321A/AC6321A_Datasheet V1.3.pdf` 的引脚图。
- 若不想拆机量, 也可只提供主板高清正反面照片, 我可协助标注并反推走线。

## 判定后交付
把按键→GPIO 映射表回填到 src/firmware 的按键配置即可进入构建。
