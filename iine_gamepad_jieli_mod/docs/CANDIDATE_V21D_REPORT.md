# 候选固件 v21d (67B 复合描述符，原槽位)

日期: 2026-10-19

## 背景
- v21b 能刷入，但无法与 Kindle 建立连接。
- v21b 使用 87B 描述符，放在 app.bin 内部 `0x23330`，并保留
  LED 输出报告。
- 为排除“描述符长度/输出报告/落点”三个变量，v21d 采用最小改动。

## v21d 修改
- 复合描述符 67B，直接写回原厂键盘描述符槽位 `0x2260A`。
- 原描述符槽位 69B，新描述符 67B，剩余 2B 保持原值。
- 选择器指针不变 (`0x1E2272A`)，只把长度 69 -> 67。
- 去掉 LED 输出报告，描述符比原厂还短 2B。
- 输入报告仍为 8 字节:
  `modifier + reserved + 4 keys + 16-bit Consumer usage`。
- 键表仍为 type 4 `04 00 70/6f 00 00 00`。
- Consumer usage 写到聚合缓冲 `+38` (键盘 key slot 5/6)。

## 补丁

| app.bin 偏移 | 原值 | 新值 | 说明 |
|---|---|---|---|
| 0xABBE | `50 74` | `30 74` | 长度 69 -> 67 |
| 0xC7C6 | `e8 58` | `38 59` | Consumer usage1 -> +38 |
| 0x2260A | 原键盘描述符 | 67B 复合描述符 | 原槽位覆盖 |

键表:
```
左: 04 00 70 00 00 00
右: 04 00 6f 00 00 00
```

## 为什么这个版本更可能连接
- 描述符在原厂已验证可用的槽位，不需要新地址。
- 长度 67B < 原厂 69B，不会触发 Report Map 长度上限。
- 去掉输出报告，排除输出报告声明导致的 HID 初始化失败。
- 只保留键盘 + Consumer 输入，结构与参考实现最接近。

## 刷写
官方工具人工刷写，Codex 不自动写入。刷后 Kindle 忽略旧设备后
重新配对，测试连接、翻页、左右亮度。

## 若仍无法连接
问题在复合 Consumer 字段或 Report ID 2 报告构造，而不是长度/
落点。下一步应回退 v20，抓取实际广播包、Report Map 和 HID 报告，
再决定是否改用 6-key/10-byte 的参考布局。
