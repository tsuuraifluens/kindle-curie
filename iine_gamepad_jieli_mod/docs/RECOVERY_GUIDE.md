# 原厂恢复步骤与故障处理

## 当前状态
用户已报告原厂固件可备份并恢复；v18/v19 也已实机刷入并正常启动，
说明官方升级链路可用。本指南仍要求每次刷写前确认工作区外备份存在。

## 前置: 独立备份 (务必先做)
1. 将 `iine_gamepad_jieli_mod/analysis/firmware/` 下 3 个文件复制到工作区之外(如另一块硬盘/网盘)。
2. 核对 SHA-256 (见 analysis/firmware/MANIFEST.md)。
3. "已备份"不等于"可恢复": 在唯一实验设备上, 把"能刷回原厂"作为独立验证项。

## 原厂升级步骤 (来自升级步骤.doc 提取)
1. 打开 `L1161 固件升级程序_1.4.40.exe`。
2. 选择烧录文件: `L1161 L1162.ufw`。
3. 勾选 "擦除整个FLASH" 与 "成功后复位"。
4. 手柄开机 → 插 USB 数据线 → 按住 "配对 + B键" 2 秒 → 灯灭进入升级模式 → 工具状态栏显示 ONLINE。
5. 点击升级 → 等待 "升级成功"。

## 故障处理
- 若刷写后无法启动: 立即停止其他修改, 按上述步骤重新刷入原厂 .ufw。
- 若升级工具不识别设备: 检查 USB 线(需数据线)、确认进入升级模式的按键组合、确认设备管理器中出现设备。
- 若刷写中断/失败: 保持连接, 重新进入升级模式后重试原厂文件, 不要断电或拔线。
- 若原厂文件也被工具拒绝: 停止操作, 记录工具报错信息, 勿尝试其他未确认文件。

## 安全红线
- 不自动执行任何向真实设备写入的操作。
- 不勾选未经确认的选项; 不擦除启动区以外的未知区域。
- 变砖后优先恢复原厂, 不做实验性烧录。
