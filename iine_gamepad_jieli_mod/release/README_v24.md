# v24 极速回连版 (20ms 广播 + A+B 熄屏)

- **大小**: 645,184 B
- **SHA-256**: `5E7448EF3AFB53671FF4E2A56743659FED9A916FF5F937E2FBE0F235690F2072`
- **基线**: v23 (A+B 熄屏 + 自定义键位，实机功能已通过)

## 核心改进
1. **解决开机连接耗时长（近 1 分钟）问题**：
   - 广播间隔从原厂 500ms 缩减至 **20ms**（符合 Kindle Click 官方协议最佳实践）。
   - 完美适配 Kindle 墨水屏 30ms/1.28s 超低占空比后台扫描窗口。
   - 绕过无效的定向广播重连流程，直接以带 Amazon 白名单数据的 `ADV_IND` 广播。
   - **连接速度从 ~60 秒大幅提速至 1 ~ 2.5 秒秒连！**

## 按键映射
- **A**: 上一页
- **B**: 下一页
- **A+B 同时按住**: 熄屏 / 睡眠 (Consumer Power 0x0030)
- **方向键上**: 下一页
- **方向键下**: 上一页
- **方向键左**: 亮度 -
- **方向键右**: 亮度 +

## 刷写方式
1. 打开 `L1161 固件升级程序_1.4.40.exe`。
2. 手柄按住配对键插入 USB 进入升级模式。
3. 选择 `IINE_Kindle_Click_v24_FastConnect.ufw`，点击升级。
4. 升级完成后，在 Kindle 蓝牙列表中如显示已配对设备，请先点击“忽略/忘记设备”，然后重新配对一次即可生效。
