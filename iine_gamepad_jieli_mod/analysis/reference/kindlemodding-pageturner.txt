com.lab126.todo.kaf  com.lab126.transfer  com.lab126.volumd  com.lab126.winmgr     Settings   Light Mode  Dark Mode        Kindle Click     Kindle Click is a page turning remote announced on 1st October 2026 for $35.  Features:   Forward  Backward  Brightness increase/decrease  Sleep   The device is internally referred to as  kindleremote .  HID  The Kindle Click is a HOGP (HID over GATT Profile) device. Battery life is reported via a standard BLE battery service ( 0x180F ).  (needs confirming)   Discovery  The Kindle detects the Kindle remote as a HID device with a vendor ID of  0x0171  and a product ID of  0x0443 .  Control  The Kindle Click sends standard HID keycodes for each action:      Action  Key      Page Forward  KEY_PAGEDOWN    Page Back  KEY_PAGEUP    Brightness Up  KEY_BRIGHTNESSUP    Brightness Down  KEY_BRIGHTNESSDOWN    Sleep  KEY_POWER      OS Implementation  The device is handled by  /usr/bin/acsbtfd  which performs the main pairing, discovery, and HID logic.  /usr/bin/input_manager  handles mapping the inputs (and the vid/pid storage?) and is data-driven, hence the JSON files attached to this page.
