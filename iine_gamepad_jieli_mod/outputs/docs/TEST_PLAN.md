## 2. 协议测试 (BLE 抓包/分析器)

- [ ] 设备名与识别字段。
- [ ] GATT: HID 0x1812 (Report Map 正确), DIS PnP 01 71 01 43 04 vv vv, Battery 0x180F/0x2A19。
- [ ] HID 报告描述符与 §4.1 一致。
- [ ] 按下/释放成对; 重复报告; 配对/连接; 断连恢复; 电量通知。
- 未实测项标记为"未验证"。

## 3. 按键测试用例 (自动化/手动)
- 每键单击一次; 连续快速点击; 长按亮度; 长按睡眠组合; 连接中按键; 断连中按键; 重连后按键; 低电量; 长空闲; 重启后重连。
- 检查: 按键丢失、重复触发、释放丢失、状态卡死、异常重连。

## 4. Kindle 实机测试 (仅在前述通过后)
1. Kindle 能否发现遥控器 → 2. 配对 → 3. 持续连接 → 4. 前进/后退 → 5. 亮度调节 → 6. 睡眠 → 7. 断连重连 → 8. Kindle 重启后恢复 → 9. 长时间闲置恢复 → 10. 原手柄电源/充电/按键正常。
