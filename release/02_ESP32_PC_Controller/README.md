# 方案二：ESP32 电脑控制方案 (ESP32 PC & Web Remote Controller)

本方案是一套面向 PC 桌面与移动端的交互式图形化控制套件。通过数据线将已烧录 ESP32 固件的板卡插入电脑 USB 接口，即可将电脑键鼠、桌面悬浮窗以及手机局域网网页无缝转化为 Kindle 墨水屏翻页控制器！

---

## 核心特性与功能

1. **暗黑现代桌面 GUI (Tkinter)**:
   - 界面布局专为阅读场景优化，提供大号触摸/点击按钮（上一页、下一页、亮度加减、睡眠唤醒）。
   - 窗口支持「**置顶浮动模式 (Always on Top)**」，看书办公时可在屏幕角落轻便使用。
2. **全局窗口键盘快捷键 (Hotkeys)**:
   - **下一页 (Next Page)**: `Space (空格)` / `Right (右方向键)` / `PageDown` / `D` / `Down (下方向键)`
   - **上一页 (Prev Page)**: `Left (左方向键)` / `PageUp` / `A` / `Up (上方向键)`
   - **亮度调节 (Brightness)**: `+` 或 `=` (调亮), `-` 或 `_` (调暗)
   - **双键合盖睡眠 (Sleep Chord)**: `S` (同时注入 PageUp `0x4B` + PageDown `0x4E` 触发熄屏)
   - **电源休眠 (Power)**: `P` (发送标准 Consumer Power `0x0030`)
3. **内置局域网 Web 遥控器 (`http://localhost:8088`)**:
   - 程序启动后自动开启轻量 HTTP 遥控服务器。
   - 同局域网下的手机或平板打开浏览器访问控制端显示的 IP（如 `http://192.168.x.x:8088`），即可在手机触屏上直接点按翻页！
4. **实时双向遥测监控**:
   - 实时显示串口连接状态、Kindle BLE 配对连接状态、远端 Kindle 蓝牙 MAC 地址。
   - 实时电池电量上报、翻页指令成功计数与毫秒级延迟监控。

## 快速使用说明

### 1. 运行环境准备
- 确保电脑已安装 Python 3.8 或更高版本。
- 首次使用请双击运行 `install_deps.bat`（或执行 `pip install -r requirements.txt`）安装依赖。

### 2. 启动控制程序
- 将已刷入固件的 ESP32 插入电脑 USB 口。
- 双击运行 `launch_remote.bat`。
- 在程序主界面选择对应的 COM 端口（如 `COM3`），点击「连接串口」。
- 连接成功后，按键盘空格键即可控制 Kindle 翻页！
